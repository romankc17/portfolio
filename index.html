KaaryaOne

In development

A configurable ERP and workflow platform for Nepali businesses — one system that reshapes itself per industry instead of one rebuild per client. Web, mobile, desktop and realtime clients all run off a single API.

  • Multi-tenant by agency and branch — per-tenant module toggles and industry templates, so a clothing retailer and a distributor run the same core configured differently
  • Accounting and inventory core — invoicing, bills, expenses, cashflow, stock movements with variants and barcodes, POS sessions and role-based permissions
  • Four clients, one API — React 19 web app, Expo mobile, Electron desktop, and a Redis-backed WebSocket service for live updates
  • Built on the Nepali fiscal calendar — Bikram Sambat dates, VAT and TDS, and NCM courier integration with per-tenant tokens so COD settles into each client's own account
  • End-to-end Playwright suite gating production releases on Cloud Run

05 — About

A bit of background

I started out self-taught, writing Python because something in front of me needed automating. That hasn't really changed — it just got bigger. Today I run two products at once, which means I do the database design, the API, the web, mobile and desktop clients, the deployment, and the support conversation that follows.

Working across the whole stack on products I also operate has made me opinionated about restraint. Most business software fails here not because it lacks features but because it has too many, aimed at workflows nobody has. I'd rather ship a narrow thing that a shop owner opens every morning than a broad one they abandon in a week.

I'm open to consulting and product work, particularly where local compliance, multi-tenancy or Nepal-specific integrations are the hard part.
